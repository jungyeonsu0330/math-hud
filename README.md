# 📐 Gemini Math Live HUD

> 태블릿 & 모바일 전용 실시간 KaTeX 수학 수식 변환, Math.js 대수 검증 및 JSXGraph 인터랙티브 시각화 HUD

## ✨ 주요 기능
- **⚡ 원터치 클립보드 분석 & 스마트 자동문**: 제미니 답변 복사 후 웹앱으로 전환 시 0.1초 만에 자동 수식 정제 및 렌더링
- **📐 실시간 KaTeX 수식 변환**: 복잡한 구어체 및 TeX 수식을 선명하고 아름다운 수식으로 고속 렌더링
- **🔍 Math.js CAS 컴퓨터 대수 엔진**: 실제 대수적 등호 성립 및 계산 오류, 분모 0 조건 실시간 정밀 검증
- **📈 JSXGraph 동적 애니메이션**: 함수 그래프, 접선, 교점, 극값의 실시간 대화형 시각화
- **🌐 언제 어디서든 접속**: GitHub Pages를 통한 정식 HTTPS 지원으로 IP/네트워크 제약 제로
